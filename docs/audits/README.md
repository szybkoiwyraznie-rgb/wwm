# Audyty

Miejsce na trwałe wyniki audytów, które warto zachować dłużej niż życie jednego PR-a —
na przykład przegląd spójności bazy po większej dostawie albo analiza regresji w silniku.

Bieżący audyt poprzedniego PR-a **nie** ląduje tutaj: jego miejsce to opis PR sesji
(AGENTS.md §3). Plik w tym katalogu powstaje tylko wtedy, gdy wniosek ma wartość
dla kolejnych sesji — wtedy trafia też do `docs/LESSONS.md`, jeśli jest lekcją.

Konwencja nazwy: `RRRR-MM-DD-temat.md`.
