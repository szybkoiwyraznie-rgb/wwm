# Plany

Miejsce na plany większych przedsięwzięć, które nie mieszczą się w opisie jednego PR-a —
na przykład migracja schematu, przebudowa widoku albo podział artefaktu.

Plan sesji jest **zawsze** w opisie PR-a (AGENTS.md §3). Ten katalog służy temu, co ma
żyć dłużej: plan wieloetapowy z kolejnością kroków i kryteriami akceptacji. Plan, który
zmienia wiążącą decyzję, kończy się ADR-em w `docs/decisions/`.

Konwencja nazwy: `RRRR-MM-DD-temat.md`.
